# Security policy

Il repository contiene JSON e immagini statiche; non contiene eseguibili né codice che modifichi Windows.

Per una segnalazione riservata, usa **Report a vulnerability** nella scheda Security del repository GitHub invece di pubblicare dettagli in una issue. Includi un caso riproducibile e l'impatto, senza credenziali o dati personali.

Le modifiche ai dati devono passare la validazione automatica. Le immagini referenziate da upstream non sono considerate verificate solo perché scaricate via HTTPS.
